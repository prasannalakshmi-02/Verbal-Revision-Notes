# TCS NQT Verbal Ability Revision Notes 📚

This repository contains a comprehensive PDF of Verbal Ability notes curated from the GeeksforGeeks Verbal Ability Series. These notes are designed for quick revision for the TCS NQT (2024, 2025, 2026 Batches).

## 🔍 Topics Covered:

### Parts of Speech: Nouns, Pronouns, Verbs, Adverbs, etc.

### Articles: Definite and Indefinite rules.

### Active & Passive Voice: Quick conversion rules.

### Direct & Indirect Speech: Tense shifts and reporting rules.

### 🚀 How to use:

Download the Verbal_Revision_Notes.pdf.

Review the "Rules" sections before attempting mock tests.
